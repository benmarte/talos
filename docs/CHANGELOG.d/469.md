- **`scripts/talos.sh done` does the end-of-stage bookkeeping the playbook's "After <role> returns" blocks and its stream protocol listed (#469, slice 5 of #422).** `done <role> --issue <N> [--pr <M>] [--verdict <V>] --summary-file <F|-> [--draft] [--action-id <id>] [--tokens <n>] [--tool-uses <n>] [--duration-s <n>] [--model <m>] [--sha <sha>]` runs, in the playbook's order: the state fixes (a `RESTAMP_FAIL` strips the role's stale approval label; with `--draft` a QA `FAIL` runs `draft-pr` then drops `qa:pass`), the board status, the role relay (`pipeline-notify.sh <role> "#<N>" - <N>`, the summary on stdin), the role's `post_stage` event (`post_stage <role> <role> ...` as before; `stage_complete` stays the adapter path's own event), the spend block after a role relay, and the lifecycle event (`pr-opened`, or `blocked` for a failing verdict). The verdict is a fixed word per role (`stop reason=verdict-invalid` otherwise): validator `CONFIRMED|ALREADY_FIXED|DUPLICATE|NEEDS_MORE_INFO|SECURITY_THREAT`, developer `PR_OPENED|BLOCKED`, qa `PASS|FAIL`, reviewer `APPROVED|CHANGES`, security and adversarial `CLEAR|FINDINGS`, each role also `RESTAMP_PASS|RESTAMP_FAIL`; pm and docs take none. Output is `done=ok|duplicate`, `spend=<line>`, `warn reason=<enum>` lines and `next=continue|stop|fix-round stage=<role>|batch` (`batch`: a `--draft` review role returned findings, so one `gate fix-round` covers the whole review batch). `done` never calls `gate fix-round` and never merges. The summary reaches the verb only as a file or stdin (`--summary-file -`) and its consumers as stdin and a file, never on a command line; child stderr is relayed only as `note done=<verb> msg=<escaped>`. `--action-id <id>` (`[a-z0-9._-]{1,64}`) makes a call at-most-once: the id is recorded in `talos-done.ledger` under the git common dir (guarded by `pipeline-lock.sh`, fail closed as `stop reason=ledger-locked` after `TALOS_DONE_LOCK_S` seconds, default 10), and a repeat prints `done=duplicate` and does nothing else; the playbook does not pass it yet. `post_stage` and the spend block now each have one writer in `talos.sh` (`_talos_post_stage`, `_talos_spend`), which `gate fix-round`'s budget-blocked event, `post-merge` and `done` all use. `skills/pipeline/SKILL.md` shrinks from 92,560 B to 84,532 B (the planned -15,000 B was not reachable; validator-confirmed target about -8,500 B, `SKILL_MAX_BYTES` lowered to 84,600). Also: `talos.sh prompt` stops (`value-missing`) on an empty `templates/prompts/_stop-rule.md`, renders `none` for an empty `--prior-file`, refuses a marker with spaces inside such as `{{ NAME }}` (`unknown-placeholder`), and takes `--preamble-file <file>` (the `hooks.pre_dispatch` output, put verbatim at the top of the rendered prompt). `tests/test-talos-done.sh` pins the journal order of every role and verdict, the ledger, the pre-steps, the contract and the single writer; the tests that grepped the moved prose now read the verb (`test-skill-names`, `test-spend-wiring`, `test-free-text-as-data`, `test-restamp-dispatch`, `test-blocked-label-ownership`, `test-draft-stage-order` with regenerated fixtures, `test-skill-size`).
