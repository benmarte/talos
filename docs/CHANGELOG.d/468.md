- **`scripts/talos.sh prompt` renders the stage prompts from `templates/prompts/<role>.md` instead of the playbook carrying them (#468, slice 4 of #422).** `prompt <role> --issue <N> [--pr <M>] [--shape first|fix-round|restamp] [--draft]` prints one line, `prompt_file=<path>` (a new mode-0600 file under `${TMPDIR:-/tmp}` that the caller reads for the spawn and removes), or a `stop reason=<enum>` line (the list is `prompt-reasons:` in the script header). The nine dispatch fences of `skills/pipeline/SKILL.md` (validator, planner, PM, developer, QA, reviewer, security, docs, adversarial) moved to `templates/prompts/<role>.md`, the `If you stop, block, or ask...` rule every prompt carries to one shared partial (`_stop-rule.md`), and the re-stamp instruction to `restamp.md`. Placeholders are `{{NAME}}` over a fixed allow-list, rendered in one `python3 -I` pass with no eval and no shell expansion (the developer prompt still holds a literal `$PR_TITLE` and `$BODY_FILE`): an unknown marker is `stop reason=unknown-placeholder`, a marker with no value `stop reason=value-missing`, a value is inserted as it is and never scanned for markers again, and a marker alone on its line with an empty value drops the line. The config-derived lines (isolation note, `Required checks:` and CI wait budget, the draft line, the changelog-mode and status-fragment lines, the handoff line) are the verb's, read through `cfg` as `env` reads them. Free text (prior stage summary, CI failure data, the epic, the filtered docs paths, the re-stamp inputs) reaches the verb only in files. Shapes: `fix-round` is the developer re-dispatch (needs `--pr` and `--prior-file`; `--ci-failure-file` adds the CI provider's data as a fenced block), `restamp` is the delta re-review of QA, reviewer, security and adversarial. Not moved: the QA/reviewer evidence lines, the developer merge-base task prompt and the `hooks.pre_dispatch` paste rule stay in the playbook. Two prompt texts changed on purpose: the docs prompt's changelog-mode line is now just `CHANGELOG MODE: fragments|direct` (it read `Changelog mode: CHANGELOG MODE: ...`) and its two orchestrator-facing sentences about `docs_mode` went, and a draft review says `This is a draft review (#332): QA and CI have not run on PR #<n>`. The adapter path now pipes the file (`pipeline-agent.sh <role> - < "$PROMPT_FILE"`), so no heredoc carries issue text. `skills/pipeline/SKILL.md` shrinks from 103,585 B to 92,560 B (the planned -28,000 B was not reachable; validator-confirmed target about -12,000 B, `SKILL_MAX_BYTES` lowered to 92,600). `tests/test-talos-prompt.sh` pins every role and shape with golden fixtures (`tests/fixtures/talos-prompt/`), the rendering rules and the safety lines; `tests/test-stage-done-when.sh` and the tests that grepped the old fences now read the templates or render a prompt, and `tests/fixtures/skill-steps-3c-4.md` is regenerated.
