- **Scripts no longer print `printf: write error: Broken pipe` when SIGPIPE is ignored (#494).** The Actions runner ignores SIGPIPE, so `printf '%s\n' "$v" | grep -q PAT` made printf hit EPIPE when `grep -q` exited on its first match, and bash printed a write error on stderr (the flake that failed PR #491's CI at `scripts/pipeline-draft-check.sh`). The sites in `pipeline-draft-check.sh`, `bootstrap-board.sh`, `pipeline-notify.sh`, `pipeline-status-file.sh`, `install.sh` and in 15 tests now read the value through a here-string (`grep -q PAT <<<"$v"`), with the same result. `tests/test-unsafe-cleanup-guard.sh` gains rule R5, which flags `printf|echo ... | grep -q` in `scripts/`, `tests/` and `install.sh`; its `R5_ALLOW` list holds the files other open PRs still edit (`pipeline-vcs.sh` and `pipeline-agent.sh`) and a stale entry fails, so the follow-up that fixes them empties it. `tests/test-draft-check.sh` runs the grep fallback on a large workflow under `trap '' PIPE` and asserts empty stderr.
